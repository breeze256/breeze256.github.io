## 最大公约数及最小公倍数

一组整数的最大公约数（gcd），是指所有公约数里面最大的一个。
一组整数的最小公倍数（lcm），是指所有正的公倍数里面，最小的一个数。

$\gcd(a, b) = \gcd(a, a + b) = \gcd(a, ka + b)$

### 欧几里得算法求 GCD

针对一般情况（小整数），可以利用“辗转相除”来求 GCD。

```cpp
int gcd(int a, int b) {
    return b ? gcd(b, a % b) : a;
}
```

### 求 LCM

由于有 $c * d = \gcd(c, d) * \rm{lcm}(c * d),$
故 $\rm{lcm}(c * d) = \dfrac{c * d}{\gcd(c, d)}.$

```cpp
int lcm(int a, int b) {
	return (a * b / gcd(a, b));
}
```
