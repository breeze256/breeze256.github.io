恰逢 H 国国庆，国王邀请 $n$ 位大臣来玩一个有奖游戏。首先，他让每个大臣在左、右手上面分别写下一个整数，国王自己也在左、右手上各写一个整数。然后，让这 $n$ 位大臣排成一排，国王站在队伍的最前面。排好队后，所有的大臣都会获得国王奖赏的若干金币，每位大臣获得的金币数分别是：排在该大臣前面的所有人的左手上的数的乘积除以他自己右手上的数，然后向下取整得到的结果。

国王不希望某一个大臣获得特别多的奖赏，所以他想请你帮他重新安排一下队伍的顺序，使得获得奖赏最多的大臣，所获奖赏尽可能的少。注意，国王的位置始终在队伍的最前面。

首先，先画一个草图，

$$
\dots, A[a_n, b_n], B[a_{n + 1}, b_{n + 1}], \dots
$$

我们要知道 $A$ 和 $B$ 到底能不能交换，我们就要比较它们交换前后对他们的贡献值的影响。

我们先假设他们可以交换。故交换后有，

$$
\dots, B[a_{n + 1}, b_{n + 1}], A[a_n, b_n], \dots
$$

然后我们根据题目，可以计算他们交换前后的值，

$$
Before: 
A:\; \dfrac{\prod_{i = 1}^{n - 1}a_i}{b_n} \;
B:\; \dfrac{\prod_{i = 1}^na_i}{b_{n + 1}} \;
After:
A:\; \dfrac{\prod_{i = 1}^{n - 1}a_ia_{n + 1}}{b_n} \;
B:\; \dfrac{\prod_{i = 1}^{n - 1}a_i}{b_{n + 1}}
$$

由于前面的值不会影响此处 $A$ 与 $B$ 对答案的贡献，我们可以直接把连乘消去，

$$
Before: 
A:\; \dfrac{1}{b_n} \;
B:\; \dfrac{a_n}{b_{n + 1}} \;
After:
A:\; \dfrac{a_{n + 1}}{b_n} \;
B:\; \dfrac{1}{b_{n + 1}}
$$

故 $A$ 与 $B$ 对答案的贡献可以表示为，

$$
Before: 
\max\left(\dfrac{1}{b_n}, \dfrac{a_n}{b_{n + 1}}\right) \;
After:
\max\left(\dfrac{a_{n + 1}}{b_n}, \dfrac{1}{b_{n + 1}}\right)
$$

由于我们不难判断，$\dfrac{a_n}{b_{n + 1}} > \dfrac{1}{b_n}$，$\dfrac{a_{n + 1}}{b_n} > \dfrac{1}{b_{n + 1}}$，故交换前后对答案的贡献变为，

$$
Before:
\dfrac{a_n}{b_{n + 1}} \;
After:
\dfrac{a_{n + 1}}{b_n}
$$

则交换需要满足的条件为 $\dfrac{a_n}{b_{n + 1}} > \dfrac{a_{n + 1}}{b_n}$，通分即为，

$$
a_nb_n > a_{n + 1}b_{n + 1}
$$

故第 $n$ 项若能与第 $n + 1$ 项交换，则其左右手之积需大于第 $n + 1$ 项左右手之积。

``` cpp
bool cmp(node A, node B) {
  /* 这里的 A 相当于第 n + 1 项. */
  return A.a * A.b < B.a * B.b;
}

int main() {
  /* 贪心重新排序. */
  sort(a + 1, a + n + 1, cmp);
}
```
